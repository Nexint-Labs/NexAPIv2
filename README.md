## Requirements

- NPM
- NodeJS
- .env file (example has been provided)
- nothing else lol

## Install

1. Clone the repository.

```
git clone https://github.com/Nexint-Labs/NexAPIv2
```

2. Install dependancies

```
npm install
```

3. Create the .env file with the example

4. Configure settings in `/config`

5. Launch the server (and pray it works)

```
npm start
```
